Harmonisation Test Bench

A manual test plan for the harmonisation in your local FIRMS app, plus two calculators that recompute the expected results on their own, so you can check the app's output against an independent calculation.

Before you start

  1. Run python server.py in C:\cesti\nasabbl and open the app (http://localhost:8000) next to this page. This page is also served at http://localhost:8000/test.
  2. Most tests use test area A: date 2026-10-13, day range 1, area -44.6,-8.7,-43.9,-8.1 (a fire cluster in Maranhão/Piauí, Brazil).
  3. Click any column header in the app to sort it. Copy all rows under a table copies it with its header, ready to paste into the cell aggregator here.
  4. Known answers below were recorded from FIRMS on 14 Nov 2026. NASA occasionally reprocesses NRT data, so a small count difference means re-check, not automatically fail.

Cell aggregator

This recomputes the grid comparison independently: Aqua only, one VIIRS satellite, cells keyed by grid square + date + day/night, FRP summed, and a common minimum fire size.
